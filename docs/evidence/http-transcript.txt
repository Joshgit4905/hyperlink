# 4) Renewal: refresh token rotation

HTTP/1.1 200 OK
set-cookie: rt=mRxAO9zU8t…(opaque); Max-Age=604800; Path=/auth; Expires=Thu, 05 Nov 2026 02:02:22 GMT; HttpOnly; Secure; SameSite=Strict
cache-control: no-store
{"accessToken":"eyJhbGciOiJSUzI1…(JWT truncated)","tokenType":"Bearer","expiresIn":900,"user":{"id":"0fe4ecb2…","email":"demo@aroma.test","name":"Demo Customer","role":"customer"}}

$ curl -i -X POST http://localhost:4000/auth/refresh --cookie "rt=<cookie #1>"   # replay of an already-used token
HTTP/1.1 401 Unauthorized
set-cookie: rt=; Path=/auth; Expires=Thu, 01 Jan 1970 00:00:00 GMT; HttpOnly; Secure; SameSite=Strict
{"error":"refresh_reused","message":"Session revoked. Please sign in again."}

$ curl -i -X POST http://localhost:4000/auth/refresh --cookie "rt=<cookie #2>"   # whole family was revoked
HTTP/1.1 401 Unauthorized
set-cookie: rt=; Path=/auth; Expires=Thu, 01 Jan 1970 00:00:00 GMT; HttpOnly; Secure; SameSite=Strict
{"error":"refresh_reused","message":"Session revoked. Please sign in again."}
